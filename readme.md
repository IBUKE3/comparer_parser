# Задача
Вариант 12. "Парсинг сайта и сбор данных". Программа скачивает статью с википедии, обрабатывает ее и производит сравнение с текстовым файлом пользователя. Программа выделяет именованные сущности, токены и леммы, ведет подсчет токенов и лемм. В случае сравнения программа находит общие и уникальные леммы, рассчитывает коэффициент Жаккара и косинусное сходство TF-IDF векторов. Также из википедии выделяются ссылки на другие страницы википедии

# Важно
Для того, чтобы посмотреть, как происходит взаимодействие с программой, необязательно ее запускать локально. Доступ к ней есть (или должен быть) по адресу 31.77.109.249 - правда, работает оно очень медленно из-за того, что VPS не был рассчитан под такое.

# Установка
Для начала вставьте свой токен с Hugging Face в начале файла app.py - без него будут очень долго грузиться веса

```bash
conda env create -f environment.yaml
conda activate parser_yaml
```

# Запуск программы
Для запуска программы активируйте среду conda (если она еще не активирована) и введите, находясь в ней:
```bash
streamlit run <путь до папки проекта>\app.py
```
Приложение будет запущено по адресу http://localhost:8501 (должно открыться автоматически). Далее вставьте ссылку на статью на википедии, загрузите файл (кодировка utf-8, оптимальное расширение - .txt). После этого нажмите кнопку "Начать сравнение" и дождитесь его завершения
